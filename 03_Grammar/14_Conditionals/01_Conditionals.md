# Phase 14: Conditionals

Welcome to Phase 14! You've mastered **verbs**, **nouns**, **pronouns**, **adjectives**, **adverbs**, **articles & determiners**, **prepositions**, **conjunctions**, **modals**, **voice**, and **narration**. Now it's time to explore **conditionals** — sentences that express "if" situations and their results.

Think of it this way: *Conditionals are "if-then" sentences. They express what happens, will happen, or would happen under certain conditions. "If it rains, I stay home" (Zero). "If it rains, I will stay home" (First). "If it rained, I would stay home" (Second). "If it had rained, I would have stayed home" (Third). Conditionals allow you to express possibilities, hypotheticals, and regrets with precision.*

| Type | Time Frame | Formula | Example |
|------|------------|---------|---------|
| **Zero** | General truth | If + Present Simple, Present Simple | If you heat water, it boils. |
| **First** | Real future | If + Present Simple, Will + Base Verb | If it rains, I will stay home. |
| **Second** | Unreal present | If + Past Simple, Would + Base Verb | If I had money, I would travel. |

## 1. Zero Conditional

### 📚 Learn: The Concept

**Definition:** The **zero conditional** expresses general truths, scientific facts, and habits. It describes situations that are always true.

**Key Points:**
- Expresses general truths and facts
- The result is always true
- Can use "if" or "when"
- Both clauses are in the present simple

### 📐 Study: Sentence Structures

**Structure: Zero Conditional**
```
[IF] + [PRESENT SIMPLE] + [,] + [PRESENT SIMPLE]
If + you heat + water, + it boils.
If + it rains, + I stay home.
```

**Alternative: When instead of If**
```
[WHEN] + [PRESENT SIMPLE] + [,] + [PRESENT SIMPLE]
When + you heat + water, + it boils.
When + it rains, + I stay home.
```

### 👀 See: Examples

**Scientific Facts:**
- "**If** you heat water, **it boils**."
- "**If** you freeze water, **it turns** into ice."
- "**If** you mix red and blue, **you get** purple."
- "**If** you drop an egg, **it breaks**."

**General Truths:**
- "**If** you don't eat, **you get** hungry."
- "**If** you study hard, **you succeed**."
- "**If** you exercise regularly, **you stay** healthy."
- "**If** you don't water plants, **they die**."

**Habits/Routines:**
- "**If** I wake up late, **I miss** the bus."
- "**If** she feels tired, **she goes** to bed early."
- "**If** they have time, **they visit** their grandparents."
- "**If** I drink coffee, **I can't sleep**."

**With "When":**
- "**When** you heat water, it boils."
- "**When** it rains, the streets get wet."
- "**When** I exercise, I feel better."
- "**When** she studies, she uses flashcards."

**If vs. When:**
- **If** = uncertain (may or may not happen)
- **When** = certain (will happen)

**Zero Conditional Formula:**
```
If/When + Present Simple, Present Simple
```

### ⚠️ Learn: Common Mistakes

| Mistake | Correction |
|---------|------------|
| If you will heat water, it boils. | If you **heat** water, it boils. |
| If you heat water, it will boil. (First) | If you heat water, it **boils**. (Zero) |
| If I will wake up late, I miss the bus. | If I **wake** up late, I miss the bus. |
| If you heat water, it boil. | If you heat water, it **boils**. |

## 2. First Conditional

### 📚 Learn: The Concept

**Definition:** The **first conditional** expresses real and possible situations in the future. It describes what will happen if a certain condition is met.

**Key Points:**
- Expresses real future possibilities
- The condition is likely to happen
- Use present simple in the if-clause
- Use will/can/may + base verb in the result clause

### 📐 Study: Sentence Structures

**Structure: First Conditional**
```
[IF] + [PRESENT SIMPLE] + [,] + [WILL + BASE VERB]
If + it rains, + I will stay home.
If + she studies, + she will pass the exam.
```

**Structure with Modal Verbs:**
```
[IF] + [PRESENT SIMPLE] + [,] + [MODAL + BASE VERB]
If + you study, + you can pass the exam.
If + she calls, + I might answer.
```

**Structure with Imperative:**
```
[IF] + [PRESENT SIMPLE] + [,] + [IMPERATIVE]
If + you see him, + tell him to call me.
If + you have questions, + ask me.
```

**Structure in Negative Form:**
```
[IF] + [DOESN'T/DON'T] + [V1] + [,] + [WON'T] + [V1]
If + it doesn't rain, + we won't stay home.
If + she doesn't study, + she won't pass.
```

### 👀 See: Examples

**Future Possibilities:**
- "**If** it rains, **I will stay** home."
- "**If** she studies hard, **she will pass** the exam."
- "**If** we leave now, **we will catch** the train."
- "**If** you eat too much, **you will get** sick."
- "**If** they don't hurry, **they will miss** the bus."

**With "Can":**
- "**If** you study hard, **you can pass** the exam."
- "**If** we save money, **we can travel** abroad."
- "**If** you practice, **you can improve** your English."

**With "May/Might":**
- "**If** she calls, **I might answer**."
- "**If** it rains, **we may cancel** the picnic."
- "**If** he comes, **we might go** to the park."

**With Imperative:**
- "**If** you see him, **tell** him to call me."
- "**If** you have questions, **ask** me."
- "**If** you finish early, **call** me."

**First Conditional Formula:**
```
If + Present Simple, Will + Base Verb
```

### ⚠️ Learn: Common Mistakes

| Mistake | Correction |
|---------|------------|
| If it will rain, I will stay home. | If it **rains**, I will stay home. |
| If she studies, she passes. (Zero) | If she studies, she **will pass**. (First) |
| If you will come, I will be happy. | If you **come**, I will be happy. |
| If I have time, I will help you. (✓) | If I **have** time, I will help you. |

## 3. Second Conditional

### 📚 Learn: The Concept

**Definition:** The **second conditional** expresses unreal, imaginary, or unlikely situations in the present or future. It describes what would happen if something were different.

**Key Points:**
- Expresses unreal/imaginary situations
- The condition is unlikely or impossible
- Use past simple in the if-clause
- Use would/could + base verb in the result clause

### 📐 Study: Sentence Structures

**Structure: Second Conditional**
```
[IF] + [PAST SIMPLE] + [,] + [WOULD + BASE VERB]
If + I had + money, + I would travel.
If + she studied + harder, + she would pass.
```

**Structure with "Were" (Formal):**
```
[IF] + [WERE] + [SUBJECT] + [,] + [WOULD + BASE VERB]
If + I were + you, + I would study harder.
If + she were + here, + she would help us.
```

**Structure with "Could":**
```
[IF] + [PAST SIMPLE] + [,] + [COULD + BASE VERB]
If + I had + money, + I could travel.
If + she studied + harder, + she could pass.
```

**Structure in Negative Form:**
```
[IF] + [PAST SIMPLE] + [,] + [WOULDN'T + BASE VERB]
If + I had + money, + I wouldn't stay home.
If + she studied + harder, + she wouldn't fail.
```

### 👀 See: Examples

**Unreal Present Situations:**
- "**If** I had money, **I would travel** the world."
- "**If** she studied harder, **she would pass** the exam."
- "**If** we lived in Paris, **we would speak** French."
- "**If** I knew the answer, **I would tell** you."
- "**If** he had a car, **he would drive** to work."

**With "Were":**
- "**If I were** you, **I would accept** the job."
- "**If she were** here, **she would help** us."
- "**If I were** rich, **I would buy** a mansion."
- "**If he were** taller, **he would play** basketball."

**With "Could":**
- "**If** I had money, **I could travel**."
- "**If** she studied harder, **she could pass**."
- "**If** we lived near the beach, **we could swim** every day."

**Advice (If I were you):**
- "**If I were** you, **I would see** a doctor."
- "**If I were** you, **I would study** harder."
- "**If I were** you, **I wouldn't** worry."
- "**If I were** you, **I would take** the job."

**Second Conditional Formula:**
```
If + Past Simple, Would + Base Verb
```

**Important:** In the second conditional, we often use "were" instead of "was" for all subjects in formal English.

### ⚠️ Learn: Common Mistakes

| Mistake | Correction |
|---------|------------|
| If I have money, I would travel. | If I **had** money, I would travel. |
| If I was you, I would go. | If I **were** you, I would go. |
| If she studies harder, she would pass. | If she **studied** harder, she would pass. |
| If I had money, I will travel. | If I had money, I **would** travel. |

**Second Conditional vs. First Conditional:**

| First (Real) | Second (Unreal) |
|--------------|-----------------|
| If it rains, I **will stay** home. | If it **rained**, I **would stay** home. |
| If I **have** time, I **will help**. | If I **had** time, I **would help**. |

## 4. Third Conditional

### 📚 Learn: The Concept

**Definition:** The **third conditional** expresses unreal, imaginary situations in the past. It describes what would have happened if something had been different.

**Key Points:**
- Expresses unreal past situations
- The condition cannot be changed
- Use past perfect in the if-clause
- Use would have + past participle in the result clause

### 📐 Study: Sentence Structures

**Structure: Third Conditional**
```
[IF] + [PAST PERFECT] + [,] + [WOULD HAVE + V3]
If + I had studied + harder, + I would have passed.
If + she had left + earlier, + she would have arrived on time.
```

**Structure with "Could Have":**
```
[IF] + [PAST PERFECT] + [,] + [COULD HAVE + V3]
If + I had studied + harder, + I could have passed.
If + she had left + earlier, + she could have arrived on time.
```

**Structure in Negative Form:**
```
[IF] + [PAST PERFECT] + [,] + [WOULDN'T HAVE + V3]
If + I had studied + harder, + I wouldn't have failed.
If + she had left + earlier, + she wouldn't have been late.
```

### 👀 See: Examples

**Regrets:**
- "**If** I had studied harder, **I would have passed** the exam."
- "**If** she had left earlier, **she would have arrived** on time."
- "**If** we had taken a taxi, **we wouldn't have missed** the flight."
- "**If** I had known, **I would have helped** you."
- "**If** he had listened, **he wouldn't have made** that mistake."

**With "Could Have":**
- "**If** I had studied harder, **I could have passed**."
- "**If** she had left earlier, **she could have arrived** on time."
- "**If** we had saved money, **we could have bought** a house."

**Past Unreal Situations:**
- "**If** I had been born in France, **I would have spoken** French."
- "**If** she had taken the job, **she would have moved** to London."
- "**If** we had arrived earlier, **we would have seen** the beginning."
- "**If** they had invited me, **I would have gone** to the party."

**Third Conditional Formula:**
```
If + Past Perfect, Would Have + Past Participle (V3)
```

### ⚠️ Learn: Common Mistakes

| Mistake | Correction |
|---------|------------|
| If I studied harder, I would have passed. | If I **had studied** harder, I would have passed. |
| If I had studied harder, I would pass. | If I had studied harder, I **would have passed**. |
| If I had went, I would have seen her. | If I had **gone**, I would have seen her. |
| If I knew, I would have helped. | If I **had known**, I would have helped. |

**Third Conditional vs. Second Conditional:**

| Second (Present Unreal) | Third (Past Unreal) |
|-------------------------|---------------------|
| If I had money, I **would travel**. | If I **had had** money, I **would have traveled**. |
| If I **studied**, I **would pass**. | If I **had studied**, I **would have passed**. |

## 5. Mixed Conditionals

### 📚 Learn: The Concept

**Definition:** **Mixed conditionals** combine different time frames. They express situations where the condition is in one time and the result is in another.

**Key Points:**
- Combine different time frames
- Most common: Past condition → Present result
- Can also be: Present condition → Past result (less common)

### 📐 Study: Two Types of Mixed Conditionals

**Type 1: Past Condition → Present Result**

**Structure:**
```
[IF] + [PAST PERFECT] + [,] + [WOULD + BASE VERB]
If + I had studied + medicine, + I would be a doctor now.
If + she had taken + that job, + she would live in London now.
```

**Examples:**
- "**If** I had studied medicine, **I would be** a doctor now."
- "**If** she had taken that job, **she would live** in London now."
- "**If** we had bought that house, **we would have** more space now."
- "**If** he had listened to me, **he wouldn't be** in this situation now."

---

**Type 2: Present Condition → Past Result**

**Structure:**
```
[IF] + [PAST SIMPLE] + [,] + [WOULD HAVE + V3]
If + I were + more careful, + I wouldn't have made that mistake.
If + she knew + the truth, + she would have told you.
```

**Examples:**
- "**If** I were more careful, **I wouldn't have made** that mistake."
- "**If** she knew the truth, **she would have told** you."
- "**If** we were richer, **we would have bought** that house."
- "**If** he were a better driver, **he wouldn't have crashed** the car."

**Mixed Conditional Chart:**

| Type | If-Clause | Result Clause | Example |
|------|-----------|---------------|---------|
| Past → Present | Past Perfect | Would + Base Verb | If I had studied, I would be a doctor. |
| Present → Past | Past Simple | Would Have + V3 | If I were careful, I wouldn't have crashed. |

### 👀 See: More Examples

**Past Condition → Present Result:**
- "**If** I had taken French classes, **I would speak** French now."
- "**If** she had moved to New York, **she would work** on Wall Street."
- "**If** we had invested in Bitcoin, **we would be** millionaires now."
- "**If** he had exercised more, **he wouldn't be** overweight now."
- "**If** they had studied harder, **they wouldn't struggle** now."

**Present Condition → Past Result:**
- "**If** I were taller, **I would have become** a basketball player."
- "**If** she were more confident, **she would have applied** for the job."
- "**If** we had more money, **we would have traveled** more."
- "**If** he knew the answer, **he would have told** us."
- "**If** they were more careful, **they wouldn't have lost** their money."

**Mixed Conditional Formula:**
```
If + Past Perfect, Would + Base Verb (Past → Present)
If + Past Simple, Would Have + V3 (Present → Past)
```

### ⚠️ Learn: Common Mistakes

| Mistake | Correction |
|---------|------------|
| If I had studied, I was a doctor. | If I had studied, I **would be** a doctor. |
| If I had studied, I would have been a doctor now. | If I had studied, I **would be** a doctor now. |
| If I were careful, I wouldn't make that mistake. | If I were careful, I **wouldn't have made** that mistake. |
| If I knew, I would have told you. (✓) | If I **knew**, I would have told you. |

## 💬 Practice: Conversations

### Dialogue 1: Using First Conditional

- A: "**If** it rains tomorrow, **what will you do**?"
- B: "**If** it rains, **I will stay** home."
- A: "**If** you stay home, **I will visit** you."
- B: "**If** you visit me, **we will watch** a movie."
- A: "**If** the weather is nice, **we will go** to the park."

### Dialogue 2: Using Second Conditional

- A: "**If** you won the lottery, **what would you do**?"
- B: "**If** I won the lottery, **I would travel** the world."
- A: "**If** you had a million dollars, **would you buy** a house?"
- B: "**If** I had a million dollars, **I would buy** a big house."
- A: "**If** you were rich, **would you still work**?"
- B: "**If** I were rich, **I would still work** but less."

### Dialogue 3: Using Third Conditional

- A: "**If** you had studied harder, **what would have happened**?"
- B: "**If** I had studied harder, **I would have passed** the exam."
- A: "**If** I had known you were coming, **I would have prepared** dinner."
- B: "**If** I had called earlier, **would you have waited**?"
- A: "**If** you had called earlier, **I would have waited** for you."

### Dialogue 4: Using Mixed Conditionals

- A: "**If** you had taken that job, **where would you be** now?"
- B: "**If** I had taken that job, **I would be** in London now."
- A: "**If** you had studied medicine, **what would you do** now?"
- B: "**If** I had studied medicine, **I would be** a doctor."
- A: "**If** I were more careful, **I wouldn't have made** that mistake."
- B: "**If** I knew the answer, **I would have told** you."

## Topic: The Importance of Self-Love

### Dialogue

| Speaker | Line |
|---------|------|
| **Alexis** | I've been thinking a lot about self-love. I always thought it meant being selfish, but now I'm not so sure. |
| **Alexa** | That's a beautiful realization. Self-love isn't selfish—it's the foundation for loving others well. |
| **Alexis** | I've spent so much time criticizing myself that I forgot how to be kind to me. |
| **Alexa** | It's easy to fall into that habit. But you can't pour from an empty cup. |
| **Alexis** | I want to start loving myself more. But I don't even know where to begin. |
| **Alexa** | Start by speaking to yourself the way you would speak to someone you love. |
| **Alexis** | That sounds simple, but it's hard. I'm so used to negative self-talk. |
| **Alexa** | It takes practice. But every time you catch yourself being harsh, gently replace it with something kind. |
| **Alexis** | Like what? |
| **Alexa** | Instead of "I'm so stupid," say "I'm learning, and that's okay." Instead of "I'm not good enough," say "I'm doing my best." |
| **Alexis** | That feels so unnatural. |
| **Alexa** | It will at first. But over time, it rewires your brain to see yourself with compassion. |
| **Alexis** | I also want to start accepting compliments instead of deflecting them. |
| **Alexa** | That's a powerful step. When you receive kindness, you're allowing love in. |
| **Alexis** | I think I've been rejecting love because I didn't feel worthy of it. |
| **Alexa** | You are worthy. You always have been. Self-love is recognizing that truth. |
| **Alexis** | What about taking care of my body? I've been neglecting it. |
| **Alexa** | That's part of self-love too. Moving your body, eating nourishing food, and resting are all acts of love. |
| **Alexis** | I've been running on empty for so long. I need to prioritize my own well-being. |
| **Alexa** | That's not selfish—it's necessary. You can't care for others if you're running on fumes. |
| **Alexis** | I want to make self-love a daily practice. Even if it's small. |
| **Alexa** | That's a beautiful intention. Start today with one kind thought about yourself. |
| **Alexis** | I'll try. And I'll keep practicing, even when it's hard. |
| **Alexa** | That's what self-love is—choosing yourself, again and again. |
| **Alexis** | Thank you. I feel like I'm finally learning to be my own friend. |
| **Alexa** | That's one of the most important friendships you'll ever have. |

### Vocabulary with Meanings

| Word / Phrase | Type | Meaning |
|---------------|------|---------|
| **Self-love** | Noun | The practice of caring for and valuing yourself |
| **Selfish** | Adjective | Caring only about yourself, not others |
| **Criticizing** | Verb | Pointing out faults or flaws in yourself |
| **Pour from an empty cup** | Idiom / Phrase | To give to others when you have nothing left to give |
| **Negative self-talk** | Phrase | Inner dialogue that is critical and discouraging |
| **Catch yourself** | Phrasal Verb | To notice that you are doing something |
| **Harsh** (to yourself) | Adjective | Severe, rough, and critical |
| **Gently replace** | Verb Phrase | To change a habit with kindness |
| **Unnatural** (feeling) | Adjective | Not normal, expected, or comfortable |
| **Rewires your brain** | Verb Phrase | Changes the way your mind thinks through repetition |
| **Compassion** (for yourself) | Noun | Sympathy and concern for the suffering of others (or yourself) |
| **Deflecting** (compliments) | Verb | Redirecting or avoiding positive feedback |
| **Rejecting** (love) | Verb | Refusing or pushing away affection |
| **Worthy** | Adjective | Deserving of something good |
| **Neglecting** | Verb | Failing to give proper care or attention to something |
| **Nourishing** | Adjective | Providing what is needed for health and growth |
| **Rest** (as an act of love) | Noun / Verb | Period of relaxation and recovery |
| **Prioritize** | Verb | To treat something as more important than others |
| **Running on empty** | Idiom / Phrase | Continuing to function despite being extremely tired |
| **Daily practice** | Phrase | Something you do regularly to improve |
| **Intention** | Noun | A plan or purpose behind an action |
| **Choose yourself** | Phrase | To prioritize your own well-being and needs |

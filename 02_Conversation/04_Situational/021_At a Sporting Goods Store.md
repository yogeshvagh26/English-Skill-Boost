### Useful Phrases to Remember
- **Asking for advice:** *"I'm new to [sport] – what gear do I need?"* / *"What's the difference between these two models?"* / *"Which one is best for a beginner?"*
- **Trying on shoes:** *"The left shoe feels a bit tight – do you have a half size up?"* / *"I think I need a wider fit."*
- **Testing rackets:** *"Can I swing this racket to feel the balance?"* / *"Is this racket head-heavy or head-light?"*
- **Buying clothing:** *"I need moisture-wicking shirts for running."* / *"Do you have shorts with zippered pockets?"*
- **Accessories:** *"Do you sell grips for tennis rackets?"* / *"What type of strings do you recommend?"*
- **Payment:** *"Do you have a student discount?"* / *"Can I use my rewards points?"* / *"Is there a warranty on these shoes?"*
- **After purchase:** *"When should I replace my running shoes?"* (usually every 300-500 miles) / *"What's the best way to clean these?"*

### Practical Speaking Tips
1.  **Learn common sports terms**: Practice words like *"tread"*, *"sole"*, *"heel drop"*, *"cushioning"*, *"pronation"*, *"supination"*, *"head size"*, *"sweet spot"*, *"grip"*. This helps you understand what you're buying.
2.  **Know your foot type**: If you have flat feet, say: *"I overpronate – I need stability shoes."* If you have high arches, say: *"I supinate – I need neutral shoes with more cushioning."*
3.  **Ask about the return policy**: Running shoes and rackets often need to be tested. Ask: *"Can I return these if they don't work out after a few runs?"* – many stores offer a 30-day trial.
4.  **Check for tech features**: Some shoes have *"energy return"* or *"carbon-plated"* features. Ask: *"What technology is in this shoe?"* – if you're a serious runner.
5.  **Layering advice**: For cold weather, ask: *"What do you recommend for winter running – base layers, mid layers, and outer layers?"*
6.  **Fitting tips**: Wear the socks you'll use when trying shoes. Say: *"I'm wearing my running socks – they're a bit thicker, so the fit should account for that."*

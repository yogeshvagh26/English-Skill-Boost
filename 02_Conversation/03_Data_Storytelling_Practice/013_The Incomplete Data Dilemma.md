## 1. Situation : Quarterly Board Review – The "Incomplete Data" Dilemma

**Context:** You are a Senior Data Analyst at a global retail chain. It's the end of Q3, and you need to present the Q4 revenue forecast to the board. However, 20% of your sales data from international partners is delayed (they report on a different cadence). The CFO (Elena) wants a "solid, single number" to present to investors. You have incomplete information and need to give a forecast that is both honest and decision-ready – without being accused of "not knowing the numbers."

---

## 3. Vocabulary and Expressions

| Word/Phrase                     | Part of Speech | Meaning                                                                                | Example Sentence                                                                                 |
| ------------------------------- | -------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Data completeness**           | Noun Phrase    | The percentage of expected data that is actually available for analysis                | *We have 80% data completeness – 20% is delayed from international partners.*                     |
| **Data latency**                | Noun Phrase    | The delay between data creation and data availability for analysis                     | *Data latency of 2 weeks means we're always forecasting partially blind.*                         |
| **Imputation**                  | Noun           | The process of filling in missing data using statistical methods or assumptions        | *I used rolling averages for imputation of the missing regions.*                                 |
| **Assumption**                  | Noun           | A condition or value that you take as true for the purpose of analysis or forecasting  | *Every forecast is built on assumptions – we need to document them clearly.*                      |
| **Scenario planning**           | Noun Phrase    | A forecasting method that considers multiple possible futures (best case, worst case, likely case) | *Scenario planning helps us prepare for volatility, not just hope for the best.*                |
| **Range-based forecast**        | Noun Phrase    | A forecast expressed as a minimum and maximum value, rather than a single point        | *A range-based forecast is more honest when data is incomplete.*                                 |
| **Confidence interval**         | Noun Phrase    | A statistical range that is likely to contain the true value                           | *We have 80% confidence that the true revenue falls between $45M and $52M.*                      |
| **Sensitivity analysis**        | Noun Phrase    | Testing how different assumptions affect the final forecast                            | *A sensitivity analysis showed that a 5% change in APAC sales swings the forecast by $1M.*      |
| **Materiality**                 | Noun           | The threshold at which a variance becomes significant enough to matter                 | *A $1M swing is material to our forecast – we need to track it closely.*                         |
| **Rolling average**             | Noun Phrase    | An average calculated over a moving window of time (e.g., last 3 months)              | *I used a 3-month rolling average to impute missing data because it smooths out seasonality.*    |
| **Provisional**                 | Adjective      | Data or numbers that are subject to change once more complete data arrives             | *This is a provisional forecast – it will be updated when full data is available.*               |
| **Audit trail**                 | Noun Phrase    | A documented record of how you arrived at a particular number or conclusion            | *I documented every assumption and imputation step so you can audit the forecast.*              |
| **Transparency**                | Noun           | Being open and honest about limitations, assumptions, and uncertainties                | *Transparency builds trust – even when the data is messy.*                                       |

## 4. Key Takeaways

### Common Sentence Patterns (for Presenting Incomplete or Imperfect Data)

| Pattern                                                              | Use                                                                                    |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| *"I need to be upfront: we have [X]% data completeness – here's why."* | To immediately set expectations about data limitations.                                |
| *"Giving you a single number without acknowledging the gap would be irresponsible."* | To explain why you're presenting a range or range-based recommendation.                |
| *"I've built a [range / scenario] forecast using [method] for the missing data."* | To show you've been rigorous, not reckless.                                            |
| *"The recommended planning number is [X] – but the actual range is [Y]–[Z]."* | To provide a single number for operational use while disclosing the uncertainty.       |
| *"I can commit to updating this forecast when [data arrives]."*      | To turn a weakness (missing data) into a proactive plan.                               |
| *"The story isn't [we don't know]. The story is [we know within a range and we're being proactive]."* | To reframe the narrative (anchor pattern).                                            |
| *"I've documented all assumptions so we can revisit them if reality diverges."* | To show you're prepared for accountability and iteration.                              |

### Useful Phrases to Remember
- **Acknowledging the data gap upfront:** *"There's something you need to know before we dive into the numbers: the data isn't fully complete yet."*
- **Defending a range:** *"A range isn't uncertainty – it's honesty. It tells you the boundaries of what we know and what we don't."*
- **Pre-empting the "give me one number" demand:** *"I will give you one number for planning purposes. But I will also give you the range so you know the risk around it."*
- **Handling "why can't we wait?":** *"We need to move forward with the decision. The cost of waiting (delaying the forecast) is higher than the cost of using a provisional number and updating it."*
- **When the data finally comes in:** *"We now have 100% data. The actual number was $49M – within our projected range. Our forecast was accurate, even with the data gap."* (celebrating the win).
- **Calling out "missing data" patterns:** *"We see data delays from APAC every quarter – we should build this into our standard forecasting process."* (turning a problem into a process improvement).

### Practical Speaking Tips (for Presenting with Data Uncertainty)
1.  **Be the first to call out the weakness.** Don't wait for someone to ask: *"Is this data complete?"* You say it first. This shows honesty and builds credibility. Say: *"Before I share the forecast, I need to flag that we're operating with 80% data completeness."*
2.  **Present the "Range" as a visual (a line chart with a shaded band).** Show a central line ($48M) with a shaded area around it ($45M–$52M). This instantly communicates uncertainty without making the core number disappear.
3.  **Show the "Assumptions Table" explicitly.** Create a small table on the slide that lists every assumption you made (e.g., "APAC sales = last 3 months average", "Exchange rates = current as of Oct 1"). This signals that you've thought rigorously about the gaps.
4.  **Introduce the "Update Cadence".** Say: *"I will present this forecast today, but I will send an updated version as soon as the missing data arrives – in 2 weeks."* This gives stakeholders confidence that you're not just guessing and forgetting.
5.  **Use the "Materiality" filter.** Say: *"We have missing data for 20% of regions. However, those regions represent only 5% of total revenue – so the impact on the overall number is small."* – if the missing data isn't material, you can downplay the uncertainty.
6.  **Frame the forecast as "guidance, not gospel".** Say: *"This number is our best estimate, but it's a living number. We'll refine it as more data becomes available."* This sets the right expectation and reduces the pressure on you to be "perfect."
7.  **Provide a "Reconciliation" when the full data arrives.** When you get 100% data, present the comparison: *"Our provisional forecast was $48M. The actual turned out to be $49M – a $1M difference, which is within our projected range. Our process worked."* This validates your methodology and builds long-term trust.
